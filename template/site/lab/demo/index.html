平台自测页，不计入学习进度

课件样例：每种元素长什么样

花几分钟熟悉课件的版式。以后每天的课都由这些元素组成：文字讲解、页边注、配音动画、交互模块、小测和课末打卡。

回顾热身

每节课开头有几道回想题，题目来自前几天学过的内容。先自己想，再看参考答案，最后诚实地给自己打个分。这个分数决定周末复习哪些概念。

不往下翻：你猜这一页会出现哪几种媒介？

文字、配音动画、交互模块，外加小测。每种内容用最适合它的形式讲：概念用文字最快，过程和结构用动画，需要"手感"的用交互。

文字和页边注

正文是主线。每段最多有一句话用荧光笔标出来，那是这一段最值得记住的一句话。第一次出现的术语会加粗，比如 Token。

Embedding（向量表示）

右侧页边是"现在不用管"的区域。蓝色的 🔭 标记表示这个词以后会专门讲，现在知道有这么个东西就够了。如果你忍不住想深挖，点「问老师」问一句：老师先给个直觉，再把问题存进想深挖，到时候带你回来。

灰色的页边注是补充说明，跳过也不影响理解。

代码块右上角有复制按钮：

node tools/serve.mjs   # 启动本地学习服务器
标记意思你该怎么做
荧光笔本段重点记住它
🔭 后面会讲以后专门讲知道名字就行
🧗 Stretch有挑战的部分抓大意，没全懂也正常

一句话总结：正文是主线，页边是"以后再说"。

配音动画

适合讲过程、结构和变化。可以暂停、拖动、倍速，按 C 开关字幕。

交互模块：为什么周末要复习

交互模块用来建立"手感"：自己动手改参数，看结果怎么变。下面这个模块演示遗忘曲线：学完不复习，记忆会很快衰减；每复习一次，衰减就变慢一些。

平台按 1、3、7、14、30 天的间隔安排复习，周末的练习就是这么来的。

小测

选择题点一次就定，第一次的答案会被记录。正确率保持在 75% 到 85% 之间，说明难度刚好。

读课件时看到一个蓝色 🔭 标记的新词，最好的做法是？

  • 马上去搜索，把它彻底弄懂再往下读
  • 知道有这么个词就行，继续读；实在好奇就点「问老师」问一句
  • 跳过整段内容

🔭 标记的词以后会专门讲，到时候你已经有了需要的基础，学起来会快得多。现在深挖往往事倍功半。
