# 墨 · 主题 `ink` 的 design system

## 概念

一张宣纸，一支笔。内容写进文人画的审美里：宣纸底，墨分五色分层次，竖排书法题头，一方朱砂印。核心隐喻是**写意 vs 界画**：不确定、开放、需要体会的东西用一团化开的墨（写意）；有结构、可检验的东西用界尺画的直线（界画）。题头那滴墨晕开在乌丝栏旁边；配音动画里，唯一的写意墨团就是画面的主角，其余全是直线框。颜料只做点缀，朱砂只落在一方印、正在读的那一笔和老师的朱批上。学习者特别喜欢这套方案里文楷正文、书法标题和整体中式气质的配合，所以字体是这个主题的灵魂，不要替换。

## 适合的学科

**文科**：历史、文学、哲学、艺术、语言（含古文、外语阅读）、宗教、文化史，以及以"读和理解"为主的人文社科内容。

- 气质契合：内容本身就和书、卷、字有关，宣纸、竖排、印章不显得突兀。
- 正文是为长时间阅读设计的（文楷 19px、行高 1.9、一行约 36 字），适合文字密度高的课。
- 也可以用来做"反差"：严谨内容放进文人审美（Day 0 的样例页就是 AI 工程课）。但正式课程按学科选：工程、编程选 `quest`，数学、金融、理论选 `anatomy`。

## Tokens

三份 CSS（`lesson.css`、`component.css`、`player.css`）的 `:root` 定义同一套颜色。README 的 **token 契约**（`--paper --paper-2 --ink --pencil --rule --marker --pen --climb --red --screen --sans --mono`）在 `component.css` 和 `player.css` 里都有定义，指向下面的水墨色名。组件和场景的作者优先用契约名，需要更细的墨阶时用本主题的扩展名。

### 字体

| 变量 | 字体 | 用在哪 |
|---|---|---|
| `--kai`（= `--sans` = `--serif`） | LXGW WenKai（jsdelivr `lxgw-wenkai-webfont@1.7.0`，regular + bold）→ Noto Serif SC | 正文和全部界面文字 |
| `--brush`（播放器里是 `--lh-brush`） | "Ink Latin"（文楷粗体的西文和标点子集）→ Ma Shan Zheng（Google Fonts） | 只用于：h1、段落和目录的汉字序号、印章、「日课已毕」、动画封面标题和关键词 |
| `--mono` | Cascadia Mono / Consolas | 代码 |

字号阶梯（根字号 19px）：12 / 13.5 / 14.5（页边注、目录）/ 15.5（表格、解析）/ **19 正文，行高 1.9** / 21（takeaway、目标）/ 27（h2，文楷粗体）/ 40（段落序号，书法）/ 47.5（h1，书法竖排）。正文栏 `--main: 36rem`（约 36 字）。

马善政的西文是花体，也没有竖排标点，所以 `--brush` 前面挂了 "Ink Latin"：标题里的西文和标点自动换成文楷。

### 版式、间距、圆角、阴影

- 宽屏是三栏：左边侧边今日路线 `--toc-w: 11rem`（栏距 `--toc-gap: 2rem`），中间正文 `--main`，右边页边栏 `--side: 13rem`（栏距 `--gap: 3rem`）。1200–1299px 时三栏都收窄一点。
- 段落间距 96px，h2 下 26px，段内 1em。
- **圆角 2px**（印章 5、墨点是有机形状），不做胶囊和大圆角。
- 不用投影表现层次。浮层（弹窗、签条、窄屏目录）用"装裱"代替：`0 0 0 3–5px 纸色, 0 0 0 4–6px 清墨`，外加一层很淡的下沉阴影。配音动画是三层 box-shadow 装裱：细墨线、11px 月白绫、外沿淡墨线。

### 动效

| 什么时候 | 怎么动 | 时长 / 缓动 |
|---|---|---|
| 页面打开（全页唯一一次入场） | 题头那滴墨晕开：缩放 0.86→1，模糊 10px→0 | 1.6s，`cubic-bezier(.2,.7,.2,1)` |
| 正在读的段变了 | 目录上的朱砂一笔滑到新位置 | 0.5s，同上 |
| 答对 | 字母外面画一个圈（`conic-gradient` 遮罩扫一圈，`@property --sweep`） | 0.7s |
| 打卡刚提交（`.lh-reward.celebrate`） | 「日课」印盖下来（放大 1.6→1、轻微旋转） | 0.55s，带一点回弹 |
| 悬停、选中 | 底色或边框渐变 | 0.15–0.3s |

`html.lh-still`（QA）和 `prefers-reduced-motion` 时全部直接到终点。不加滚动入场，也不加悬浮动画。

## theme.js

- `options.number`：汉字序号（一、二、三……十一），目录和段落标题共用。
- `options.labels`：只改 `done: '日课已毕'`，其余用默认值（「后面会讲」「Stretch」等是正文和平台说明里引用的词，不改）。
- `setup(api)`：往 `.lesson-head` 加一滴墨 `.lh-ink` 和一方「日课」印 `.lh-seal`（都是 `aria-hidden`）。在 `checkin` 事件里把「日课」印放进 `.lh-emblem`；盖印动效挂在 `.lh-reward.celebrate` 上，所以只有刚提交时（fresh）才会放。

## 各元素怎么处理

- **侧边今日路线**（`nav.lh-toc`）：
  - 宽屏（≥1200px）固定在正文左侧，一直可见。
  - 左边是竖排的「今日路线」和读过的段数（0/8），像卷首的题签。右边是目录，前面一道清墨界栏细线。
  - 每项：书法汉字序号 + 标题（文楷 14px，最多两行）+ 分钟数。
  - **读过**：界栏上落一笔浓墨竖笔，序号和标题变浓墨。**正在读**：`.lh-toc-mark` 画成一笔朱砂竖笔，压在界栏上，位置跟着 `--mark-y/--mark-h` 滑动；序号变朱砂，标题加粗焦墨。**没读**：只有细线，字是重墨。Stretch 段的序号和读过的笔用石绿。
  - 窄于 1200px：收成左边缘一张竖排签条（「今日路线 6/8」），和右下角的捕获签条左右对称。悬停或用键盘 Tab 进去时展开成装裱好的目录浮层。顶部条这时显示 `.lh-track`（"7/8 段落标题"）。
- **题头**：
  - 右边是竖排书法标题，落在乌丝栏细线里（`text-wrap: balance` 让各列长短接近）。左边是落款（`.lesson-when`，竖排小字），下面盖一方朱砂「日课」印。
  - 最左边是一滴墨，下面是横排的目标。页头的路线概览（`.lh-route ol`）隐藏，只留一句总时长（侧边已经有今日路线）。
  - 窄于 640px 时标题改横排，印章隐藏。
- **顶部条**：返回、课程标题（窄屏换成"正在读"）、按分钟数等比例的小条（每段一笔：读过用重墨，正在读用朱砂，没读用清墨）、计时（超时 `.over` 变朱砂）。
- **h2**：上面一笔枯笔飞白代替分隔线（`.rule` 隐藏），左边是书法汉字序号。读过的段序号变深（`section.is-done`）。右边是分钟数。
- **段落**：文楷 19px，行高 1.9。`strong` 用焦墨，`dfn` 用花青加粗，`mark` 用藤黄淡染的一笔（`ink/mark.svg`，带水渍边）。
- **takeaway**：文楷粗体 21px，左边一竖浓墨枯笔。
- **🔭 / 🧗 页边注**：上面一小横笔，`span.emo` 去色成墨色。`aside.later` 用花青，Stretch 用石绿，普通页边注用重墨。窄屏时收进正文，横笔换成左侧竖笔。Stretch 整段左外侧有一竖石绿笔。
- **小测**：
  - `.lh-qlabel`（「小测 1/6」「回想题」）前面有一小横笔，答对后笔变石绿，答错后变朱砂。
  - 选项不加框，用清墨细线隔开。答对时字母外画一个石绿的圈；答错的选项用朱砂划掉，字母变朱砂。
  - 解析放在熟宣底上。
- **按钮**：主按钮是一抹实墨（`ink/dab.svg`，有毛边、没有飞白），字是纸色；次按钮是淡墨细线框。打卡难度、"有帮助的段"、回想题自评，选中时都是这一抹墨。
- **代码块**：熟宣底，上下各一条淡墨线，等宽 14.5px，行高 1.7。复制按钮是细框，悬停时出现。
- **表格**：上下各一道 2px 浓墨线，表头下一道 1px 浓墨线，行与行之间用清墨细线，列与列之间是清墨竖线（乌丝栏）。
- **插槽说明**（figcaption）：`span.kind`（「配音动画」「交互」）是一枚细框题签，后面是标题和时长；交互组件的 `.hint` 另起一行。
- **配音动画**：
  - 舞台是装裱好的纸本画。字幕是纸色底条加焦墨字，第二个声音用花青。
  - 开始按钮是一抹浓墨：`span.ico` + "播放"，`span.t` 时长前有一道细竖线隔开；结束时是"↻ 重播"。
  - 控制条是纸色渐隐底配墨色按钮。导出过 mp4 时出现的 `a.lh-dl` 是一枚细框小题签。
- **交互组件**：一页册页。纸底带纸纹，控件区上下各一条淡墨线。滑块是一道清墨细线，`--fill` 之前的部分是浓墨，拖的是一个墨点。按下的按钮是浓墨底。
- **捕获按钮**：右下角三张竖排签条。选中文字时浮出的是横排的浓墨条。弹窗在签条左边，带装裱边。
- **打卡结算**：左边一方「日课」印，右边是书法「日课已毕」和落款。下面是三栏数字（路线、用时、术语或小测），上下各一道浓墨线，栏与栏之间是乌丝栏。

## 交互组件和配音动画的画法规则（viz / media 照着画）

**参考实现**：样例页 `/lab/themes/ink/` 里的 `viz/reliability.html`（100 个墨点、墨线滑块）和 `media/one-request/scene.html`（纸本舞台、写意模型、界画代码框）。新组件先读这两个文件。

1. **写意画不确定，界画画确定。** 模型、概率、噪声、诠释、"不知道会怎样"用墨团晕染（`feTurbulence` + `feDisplacementMap` + 轻微模糊）。结构、流程、系统、制度、年表用直线框：2px 浓墨外框，里面再套一道 0.8px、透明度 0.55 的细线（界画双线），圆角不超过 3。外部的、不归我们管的东西用淡墨虚线框。
2. **状态靠墨色深浅。** 当前强调的用浓墨，其余降到透明度约 0.32（淡墨），**一次只亮一处**。"亮起"画成一抹浓墨加纸色字（加 `rough` 毛边滤镜），不画发光。
3. **颜料有固定语义**：
   - 朱砂 = 出错、危险（×、划掉；警告框底 `#F2DED6`）
   - 石绿 = 正确、通过（✓、圈；测试集底 `#E6EEE3`）
   - 花青 = 用户、概念标签、第二个声音
   - 赭石 = 被发现的错误、成本
   - 藤黄 = 高亮淡染

   颜色之外再加形状（× ! ✓ 圈），照顾色弱。
4. **发光改成晕染。** 原来的 `feGaussianBlur` 发光，在纸上改成带位移的淡墨晕，透明度上限约 0.25，否则会像脏污或投影。
5. **字**：场景正文用 `var(--lh-font)`（文楷），不小于 28 单位。封面标题和少数关键词用 `class="brush"`（`var(--lh-brush)`，书法），每个画面最多 1–2 处，只写中文。浓墨块上的字用纸色。组件里用 `var(--sans)`。
6. **场景调色**（SVG 里的 `C`，和 token 一致）：`bg #EEEAE0, pri #2A2622, ink #15130F, soft #3F3A34, mute #6A6359, ok #386A54, warn #A3301D, user #2E5770, meter #9A6838, hi #E4C766, panel #E5E0D3, panel2 #F4F1EA, line #A39C90`。舞台背景是纸，`#stage` 只加一层中心略亮、四角略沉的径向渐变。
7. **笔触和纹理**：现成的 mask 在 `/assets/themes/ink/ink/`：
   - `stroke.svg`：横笔，带飞白
   - `vstroke.svg`：竖笔
   - `dab.svg`：实心一抹，可以压字
   - `circle.svg`：批改的圈
   - `seal.svg`：印章外形
   - `paper.svg`：纸纹

   组件里用 `.ink-stroke` / `.ink-vstroke` 加 background-color 上色。小图形可以整层加轻微的毛边滤镜（位移 ≤2 单位）。不要每个元素单独加滤镜，同一个噪声场会让它们长得一模一样。
8. `seek(t)` 仍然必须确定。滤镜都是静态的（固定 seed），噪声不随时间变化。SVG 注释里不要出现 `--`（XML 不允许，整张图会加载失败）。

## Do

- 用墨色深浅分层次，先想焦、浓、重、淡、清，最后才想颜料。
- 大量留白、不对称：主体偏一边，另一边空着。
- 书法字只写短而重要的字：标题、序号、印、结算标题、四层的名字。
- 动效只回应用户的动作（画圈、盖印、目录朱笔移动），或者只在打开页面时出现一次（墨晕开）。
- 新纹理用 SVG 滤镜自己画，固定 seed。
- 代码、表格、小测、数字照样保持清楚：等宽字、细线、足够的对比度。

## Don't

- 不用工业水墨的套路：剪贴画远山、仙鹤、祥云纹、金色渐变、红金国潮配色，也不把一张水墨背景图铺满整页。
- 不用朱砂做普通强调或按钮色；一屏里朱砂不超过 2 处（印章 + 正在读）。
- 不在纸上做发光、霓虹、大投影和渐变按钮；不做胶囊形状和大圆角。
- 正文不用书法字体，也不用书法写长句或西文。
- 不给每段、每张卡片都加入场动画。
- 淡墨（`#8C857A`）和赭石不用于小字，对比度不够。
