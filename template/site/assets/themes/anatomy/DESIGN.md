# 主题 anatomy「图谱」

## 概念

课程页像一本安静的技术图谱：近白的纸、墨色的字、左边一直悬浮着今日路线，一块小等轴测方块指着"你在哪"，每段标题右边一条细线和一个斜体编号。页面本身几乎不出声，力气全花在图上：每个关键概念都画成一台由几十个小零件组成的等轴测"机器"，零件随操作平静地移动，旁边的读数和零件来自同一个模型。学习者"文字读得快，可视化帮助理解"，希望"不无聊"、有"20 岁的感觉"：这套语言用很少的颜色换来很强的"这是个真东西"的感觉，每天读 30–55 分钟不累眼，交互组件是每节课最想点开的那一块。

视觉语言参考 Anatomy skill（github.com/wheresryan22/anatomy，MIT，作者 Ryan）。品牌元素（手、名字、文案）没有用；`iso.js` 和 `iso.css` 是本项目自写的代码，色调数值参考了它 `kit/iso.css` 的浅色主题。

## 适合的学科

数学、金融、物理、统计、经济、算法和其它理论类：核心动作是**推导、建模、看清机制**的课。判断标准：这门课的关键概念能不能画成"做这件事的机器"（复利 = 一排越滚越大的雪球滑道；期权 = 带闸门的水箱；梯度下降 = 在曲面上滚的弹珠）。能，就用 anatomy。动手做东西为主的课用 quest，人文阅读为主的用 ink。

## Tokens

满足 `../README.md` 的 token 契约：`component.css` 和 `player.css` 的 `:root` 都定义了 `--paper --paper-2 --ink --pencil --rule --marker --pen --climb --red --screen --sans --mono`；`lesson.css` 同样定义（含 `--red`）。下面"主题自加"的变量也三处都有，组件和场景可以直接用。

### 颜色

| 变量 | hex | 用途 |
|---|---|---|
| `--paper` | `#FAFAFA` | 页面底色（课程页、组件页） |
| `--paper-2` | `#F1F1EF` | 行内代码、输入框底、解析底 |
| `--ink` | `#171717` | 正文、标题；也是唯一的"强调色" |
| `--pencil` | `#66666B` | 次要文字（#FAFAFA 上 5.6:1，AA） |
| `--rule` | `#E7E7E5` | 细线 |
| `--marker` | `#171717` | 重点、当前 = 墨色（这个主题没有荧光黄） |
| `--pen` | `#3E63DD` | 🔭 后面会讲、链接、第二个声音（speaker b）、用户 |
| `--climb` | `#23805A` | 🧗 Stretch、答对、通过 |
| `--red` | `#D93D42` | 答错、静默出错、警示、缺失 |
| `--screen` | `#FFFFFF` | 配音动画舞台（浅色） |
| 主题自加 `--card` | `#FFFFFF` | 图版、小测卡片、代码块、打卡卡片 |
| 主题自加 `--rule-2` | `#D4D4D6` | 控件边框 |
| 主题自加 `--faint` | `#8A8A8F` | 只给线、刻度、列表圆点，**不用于小字**（课程页、组件页） |
| 主题自加 `--lift` | 阴影 | 1px 细环 + 三层很淡的下沉，给"可以动手的东西" |

等轴测零件（`iso.css`，`--iso-*`，三份 CSS 都会引入）：顶面 `#FFFFFF`；侧面四档 `--iso-s3 #F6F6F3`（-x 面）`--iso-s2 #EEEEEB` `--iso-s1 #E6E6E3`（-y 正面）`--iso-s0 #DADAD7`；线 `--iso-hi #26262A`（主角）`--iso-mid #8A8A8F`（结构）`--iso-lo #B4B4B8`（底座，默认）`--iso-faint #D9D9DB`（凹槽）；`--iso-lit #000000`（现在要看的那一个）；`--iso-red #E5484D`（颜色就是主题时）。

### 字体

- `--sans`：Inter（Google Fonts）+ Noto Sans SC（本机）。正文和界面。
- 主题自加 `--serif`：Noto Serif SC。只给 `mark`（每段最该记住的一句）、`p.takeaway`、组件里的解读句、打卡结算的那句话。中文没有斜体，用"换成宋体"代替 Anatomy 的斜体衬线。
- 主题自加 `--accent`：EB Garamond Italic。只给拉丁字母和数字：段落编号 `01`、分钟数、路线计数 `3/8`、`Fig. 1`、读数、小测选项字母、结算数字。`body` 设了 `font-synthesis-style: none`，中文不会出现假斜体。
- `--mono`：Cascadia Mono / Consolas。

| 层级 | 规格 |
|---|---|
| 根字号 | 17px（≤640px 时 16.5px） |
| 正文 | 17px / 1.85，正文栏 37rem ≈ 37 个汉字 |
| h1 | 1.85rem / 1.32，600，`text-wrap: balance` |
| h2 | 1.2rem / 1.45，600；右侧 13px 分钟数 + 19px 斜体编号 |
| takeaway | 1.12rem / 1.75 宋体 500 |
| 页边注、侧边路线 | 13.5px / 1.75（路线 1.55） |
| 表格 | 15px / 1.65；表头 13px `--pencil` |
| 代码块 | 13.5px / 1.7（行高写在 `pre` 上，否则会被正文行高撑开） |
| 组件读数大数字 | Inter 300，52px，等宽数字 |

### 间距、圆角、阴影

- 段落之间 96px；h2 下 26px；图版上下 2.2em。宽屏三栏：侧边路线 15rem | 3.25rem | 正文 37rem | 3rem | 页边 13rem。
- 圆角：卡片/图版 12px；输入框 8px；按钮、标签、捕获按钮一律胶囊（999px）；表格、路线、分隔线 0。
- 阴影只有 `--lift`，只给图版、小测、代码块、打卡、捕获按钮。正文段落、页边注、侧边路线不加框。

### 动效

- 缓动 `--iso-ease: cubic-bezier(.32,.72,0,1)`；零件用弹簧（`iso.js` 的 `spring`，刚度 90、临界阻尼），不跳变。
- 只在两种时候动：回应操作（零件滑动、升起、亮起 1.6 秒；侧边方块滑到新的当前段，0.45s）；组件里一条安静的"空转"（弹珠流过流水线）。页面没有入场动画。
- 打卡刚提交时（`.lh-reward.celebrate`）徽记方块升起、✓ 描出来，只这一次。
- `html.lh-still`（QA）和 `prefers-reduced-motion` 时一次性动效直接到终点，组件里零件直接到位、弹珠停在一帧。

## 运行时元素怎么处理（结构见 README）

- **侧边今日路线 `nav.lh-toc`**：宽屏（>1300px）是 `main` 网格的第一列，`position: sticky`，一直悬浮在左边，太长时自己滚动。`p.lh-toc-h` 左边"今日路线"，右边斜体计数 `3/8`；每行 `span.no` 斜体编号（淡）+ 标题 + 斜体分钟数；读过的变深灰，正在读的变墨色。`.lh-toc-mark` 里是 theme.js 放的一块 15px 等轴测方块，用 `transform: translateY(var(--mark-y) + (var(--mark-h) − 15px)/2)` 对齐当前行的竖直中心。
  - **退路（≤1300px）**：路线回到页头下方，变成两列目录（≤640px 一列），方块隐藏；顶部条把课程标题换成 `.lh-track`（"3/8 正在读的段落"），位置仍然一直看得到。
- **顶部条**：极简。宽屏：`← 本周`、课程标题、3px 高的分钟比例条（当前段墨色、读过灰、Stretch 虚线）、学习时间（超时 `.over` 变红）。
- **页头**：一行灰色出处 → 标题 → 导语 → `nav.lh-route`：运行时的等比例条被隐藏，换成 theme.js 画的**零件条**（每段一块板，长度 ∝ 分钟，读过的压暗，正在读的升起并描墨色，Stretch 段顶面斜纹），上下两条细线夹住；下面一行"今天共 N 段"。
- **段落标题**：运行时生成 `span.n + .ttl + .rule + .min`，CSS 用 `order` 排成 `标题 ——细线—— 3 分钟 01`；正在读的段编号变墨色。`options.number` 把编号补成两位。
- **荧光笔 `mark`**：宋体 500 + 1px 墨色下划线，不画黄底。
- **takeaway**：28px 短线 + 宋体一句。
- **🔭 / 🧗**：页边小字，标签分别是蓝、绿（课文里会写"蓝色的 🔭""绿色的 🧗"，所以保留颜色）。Stretch 段左侧 1.5px 绿线。窄屏页边注收进正文，左侧细线。
- **小测**：白色卡片，`.lh-qlabel`（"小测 1/6""回想题"）是左上角的灰色小字，答对/答错后变绿/红；选项是细线分隔的行，字母斜体衬线；答对绿底 + 左侧 2px 绿线 + ✓，答错红底 + 删除线。
- **代码块**：白色图版；行内代码浅灰底。表格只有横线。
- **插槽**：配音动画是白底 16:9 图版；交互组件 iframe 透明无边框（组件自己画图版）。figcaption：`span.kind` 墨色 500，标题，`span.dur` 斜体数字；`span.hint` 另起一行。
- **打卡**：表单在白卡片里，难度是"键帽数字 + 文字"的胶囊。结算：左边 76×64 的等轴测徽记（底板 + 墨色描边方块 + 顶面绿色 ✓），右边"已打卡"；`dl.lh-stats` 画成三格读数（灰色小标签 + 斜体大数字）；结束语用宋体。
- **捕获按钮**：右下角白色胶囊组；选中文字时浮出墨色版本。
- **播放器**：白底舞台。字幕是白底细边条、墨色字，第二个声音蓝色。开始按钮 `button.lh-big` 墨色胶囊：`span.ico` ▶、"播放"、细竖线后斜体时长；重播状态（`data-state=end`）换成白底墨字。`a.lh-dl`（导出过 mp4 才出现）是细边胶囊，"↓ mp4"斜体。进度条 2px 墨色。

## 等轴测工具 iso.js（viz/media agent 直接用）

```js
import { camera, solid, cyl, ball, ns, defs, line, poly, spring, reducedMotion } from '/assets/themes/anatomy/iso.js';

const svg = document.querySelector('svg');
defs(svg);                                   // 每个 <svg> 一次：弹珠和圆柱侧面的渐变
const cam = camera({ az: 25, el: 30 });      // 方位角 0–90（25 = 长边朝前），仰角
const H = cam.fitWidth(boundingPoints, 600, 8); // 按宽度放进画框，返回 viewBox 高度
svg.setAttribute('viewBox', `0 0 600 ${H}`);
const plate = solid(svg, { tone: 'mid' }).set(x, y, z, dx, dy, dz, cam); // 长方体：顶面 + -x 面 + -y 面
plate.lit(true);                             // 现在要看的零件：墨色描边
cyl(svg).set(cx, cy, z, r, h, cam);          // 竖直圆柱（脚、柱子、数据库）
const b = ball(svg).set(cam, x, y, z, r);    // 弹珠；b.kind('bad' | 'flag' | 'ghost' | '')
const s = spring(0); s.to = 1; s.step(dt);   // 平静的弹簧，s.v 是当前值
```

- 世界坐标 x、y 在地面上，z 向上，单位约 1px；`cam.P(x,y,z)` 投影到屏幕，`cam.depth()` 越大越靠后。
- 零件的颜色全部来自 `iso.css` 的 `--iso-*`（主题的 component.css/player.css 已引入），不要在脚本里写颜色。
- 舞台（1280×720）上把线加粗：`#stage .iso-face { stroke-width: 1.5px }`，亮起 2.2px。

## 交互组件的画法（viz agent 照着做）

**参考实现**：`/lab/themes/anatomy/viz/reliability.html`（弹珠流水线：弹珠 = 请求，门架 = 一次模型调用，门架后的立柱 = 走到这一步还正确的比例，虚线管 = 丢掉的部分，托盘 = 交给用户的 100 个回答，红珠 = 静默出错，报错箱 = 被拦下的请求）。

1. **先想机器，再画图**：把概念变成"做这件事的机器"，说清一句话：什么在动、动代表什么。
2. **图版结构**：`<figure class="plate">` 四角：左上 `Fig. n`（`.corner.fig`），右上短标题（`.corner.ttl`），右下实时读数（`.corner.read`，写成公式，如 `95%⁵ = 77%`），左下可放操作提示（`.corner.hint`）。图下面放图例（细线分隔的行）和一句宋体的真实解读。
3. **零件**：用 `iso.js`。至少 40 个零件：底板 + 脚 + 凹槽 + 螺丝 + 结构 + 机构 + 主角。每个零件都立在另一个零件上；线要停在面、线或圆点上，不画引线和飘着的标签；图里不写字（最多一个刻在零件上的小标签）。
4. **色调**：底座 `lo`、结构 `mid`、主角 `hi`；一次只有一类零件 `lit`。默认亮"答案所在"的零件（参考实现里是最后一根立柱）；用户动哪个控件就亮对应零件 1.6 秒，让人学会"这个控件管机器的哪一块"。颜色只在颜色本身有意义时用（红 = 出错），颜色之外再用形状区分（✓ × !、空格位）。
5. **画的顺序**：从后往前、从下往上分层（底板 → 后排 → 后轨 → 弹珠 → 前轨和门架 → 悬臂 → 飞行物），同一层里 x 大的（更靠后）先画。
6. **数字只有一个来源**：读数、零件尺寸、托盘里的弹珠数都从同一个 `model()` 算出来；流动的弹珠只是示意，结局按同一组计数分配。
7. **动效**：弹簧过渡、时间驱动；预先建好零件，每帧只改 `d` 和坐标；IntersectionObserver 看不见时暂停；减少动效时停在一帧。
8. 控件用主题默认样式：细线滑块（`--fill` 由运行时写）、胶囊按钮、墨色"按下"、开关式 checkbox。

## 配音动画的画法（media agent 照着做）

**参考实现**：`/lab/themes/anatomy/media/one-request/scene.html`（浅色舞台，"模型"是一块等轴测芯片，其余是白底细边的平面卡片）。

- 舞台白底 + 32 单位间距的极淡点阵（参考实现里 `#stage` 的背景）。颜色只用 token：`--ink --pencil --rule --pen --climb --red --screen`（或别名 `--lh-ink --lh-soft --lh-muted --lh-line --lh-ok --lh-warn --lh-blue`）。
- "语音说到哪，画面亮到哪"：亮 = 墨色描边或墨色实心胶囊（白字）；暗 = 降低不透明度。不用发光（白底上会变脏），需要托起时用 `filter: blur` 的灰色投影（`#8A8A80`，≤0.4 不透明度）。
- 主角对象画成等轴测零件（芯片 = 底座 + 机身 + 一排引脚，正面用 `skewY` 贴字）；卡片、气泡等辅助物保持平面：白底、2px 墨色或灰色描边、14px 圆角。
- 文字 ≥28 单位；`--lh-muted` 只用于 ≥28 单位的大字；底部 15% 留给字幕和控制条。

## Do / Don't

**Do**
- 把力气花在图上；页面其余部分安静、留白、细线。
- 用宋体说"最该记住的那句话"，用斜体数字标编号、计数和读数。
- 每台机器只有一个亮的零件，亮的就是"现在该看的"。
- 让操作直接移动零件（滑块拖到 10 步，门架滑开、新门架升起、立柱一级级矮下去）。
- 读数写成公式，让人看到数字从哪来。
- 卡片阴影只给可以动手的东西。

**Don't**
- 不用荧光黄、彩色渐变、深色舞台、发光效果。
- 不在机器图里写字；标签放四角和图例。
- 不把颜色当装饰：红只表示出错，绿只表示通过/Stretch，蓝只表示 🔭、链接和用户。
- 不用 `--faint` / `--iso-mid` 写小字（对比度不够）。
- 不画只有几块大板的"扁平图"：少于 40 个零件就不像机器。
- 不让动画替代读数：所有数字都要能在图版角上或图例里读到。
